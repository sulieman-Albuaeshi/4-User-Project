# Students CRUD Demo

A simple **Students CRUD** web project built with **HTML, CSS, and JavaScript**.

This project was created as part of my learning journey with **ProgrammingAdvices**. It is a small practice project focused on improving my JavaScript and front-end development skills.

## About the Project

The application displays a list of students using data fetched from the public **JSONPlaceholder** API.

The API provides user data, which is used as the base for the student records. Additional student information such as **major** and **GPA** is generated or managed locally for demonstration purposes.

## Features

- Load student data from JSONPlaceholder
- Display students in a clean UI
- Search students by name
- Add a new student
- Edit an existing student
- Delete a student
- Form validation for name, email, and GPA
- Loading spinner while data is being loaded
- Responsive layout
- Debounced search input

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- JSONPlaceholder API

## API

The project uses:

```text
https://jsonplaceholder.typicode.com/users
```

The `/users` response is treated as student data for this demo.

> **Note:** JSONPlaceholder is a fake REST API for testing and learning. Changes made with Add, Edit, and Delete are only applied to the local JavaScript array and are not permanently stored on the server.
